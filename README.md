## Overview

The **kirby-fitzpatrick-skim-test-outliner** skill transforms cognitive writing science into deterministic rules for AI coding assistants, code reviews, and system documentation.

## Core Patterns

- **Skim Test Outliner**: Skim-Test Outlining: write action-oriented headings that communicate the full technical claim without reading body text.
- **Practical Application**: Architecture design docs allowing senior engineers to understand changes in 15 seconds.
- **Verification Gate**: Enforces clean syntax, zero filler, and deterministic causality.
